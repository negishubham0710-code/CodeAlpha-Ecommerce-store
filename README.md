# CodeAlpha Ecommerce Website

Node.js + Express + SQLite se bana hua full-stack Ecommerce website.
Features: User Signup/Login, Product Listing, Add to Cart, Order Place

## Features
- User Authentication - Signup & Login
- Product Catalog 
- Shopping Cart
- Place Order
- SQLite Database

## Tech Stack
**Backend:** Node.js, Express.js  
**Database:** SQLite3  
**Frontend:** HTML, CSS, JavaScript
